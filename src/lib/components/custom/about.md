# About custom components

Custom compoonents are components from any frameworks or libraries that are adapted to be used in a long term project customization. They have props and can be imported directedly in file to be used. Their limitation is that they have a limit of props or options for customization in a row, but some unique components that only need to have one or two props to work will be usual in more cases.
