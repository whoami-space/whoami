# About themed components

Themed compoonents are components from any frameworks or libraries that are adapted to be used in a long term project customization. They have to be copy/pasted when used 'cause they're too long or complex to pass proprieties to use them. In this case, these components are here for long term storage to copy/paste when necessary using. Other thing is that their're themed by default, so colors are adapted from the libraries/frameworks to use a custom theme basis.
